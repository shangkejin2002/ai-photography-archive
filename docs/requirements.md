# 用户中心需求说明

## 1. 项目目标

开发一个基于 React + Spring Boot + MySQL 的用户中心系统。

系统主要提供用户注册、登录、注销、查看当前登录用户，以及管理员进行用户查询和删除等功能。

---

## 2. 用户角色

### 普通用户

普通用户可以：

- 注册账号
- 登录系统
- 查看自己的登录状态
- 退出登录

### 管理员

管理员除了拥有普通用户的功能外，还可以：

- 查询用户
- 按用户名搜索用户
- 删除用户

---

## 3. 注册需求

用户注册时需要填写：

- 用户账号
- 密码
- 确认密码
- 编号

注册时需要进行以下校验：

- 用户账号不能为空
- 用户账号长度不能过短
- 密码不能为空
- 密码长度至少 8 位
- 两次输入的密码必须一致
- 编号不能为空
- 编号长度不能超过 5 位
- 用户账号不能重复
- 编号不能重复

---

## 4. 登录需求

用户使用以下信息登录：

- 用户账号
- 密码

登录成功后：

- 系统保存用户登录状态
- 用户刷新页面后仍然保持登录
- 前端可以获取当前登录用户的信息

---

## 5. 注销需求

用户可以主动退出登录。

退出后：

- 当前登录状态失效
- 再次获取当前用户时，应提示未登录

---

## 6. 用户管理需求

只有管理员可以进入用户管理页面并调用用户管理接口。

管理员可以：

- 查询全部用户
- 根据用户名进行模糊搜索
- 查看用户基本信息
- 删除指定用户

普通用户不能执行上述管理员操作。

---

## 7. 权限要求

系统需要同时进行前端和后端权限控制。

前端：

- 普通用户不显示管理员页面入口

后端：

- 管理员接口必须验证当前用户是否为管理员
- 普通用户直接调用管理员接口时，也必须被拒绝
